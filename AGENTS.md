# AGENTS.md

## Repository overview

Está encagado para documentar a detalle toda investigación relacionada al curso de Politicas Publicas y Anticorrupción a travez de fuentes
indexadas a base Scopus.

## Repository map

- `UnidadX` - Secciones divididas a travez de Unidades, X={1,2,3,4,5}.
- `/UnidadX/TemaY` - Temas en general donde Y={1,2,...,n}.
- `/UnidadX/TemaY/*` - Contenido en general.

## Working agreement

- Unicamente editar los archivos `document.tex` y las `referencias.bib`.
- Insertar información conforme a las referencias ubicadas en las
  carpetas `./referenciasPdf`.
- Respetar la estructura propuesta en la ruta raíz del proyecto llamado
`template.tex`.
- Para guiarse del tema a trabajar, la sección llamada \title en cada `document.tex` será de referencia.

## Validation

- Verificar si tiene algun compilador de latex, como TexLive para Linux
  o MkTex.
- Luedo compilar el archivo y renombrarlo con los primeros apellidos de
  los autores / redactores.
